# PREFLIGHT
Purpose: checklist the agent runs before touching code.
Last updated: 2026-09-28

1. Restate the task in one line.
2. Identify affected components (see ARCHITECTURE.md).
3. Check CONVENTIONS.md for relevant rules.
4. Check LESSONS.md for prior mistakes in this area.
5. Check DECISIONS.md for accepted ADRs that constrain the task.
6. For data work: check DATA_SOURCES.md for known issues with the inputs involved.
7. Confirm the test plan (see TESTING.md): which tests will prove the change works.
8. Flag anything ambiguous and stop to ask rather than assume.
